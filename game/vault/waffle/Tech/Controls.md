# Controls

| Input | Action |
| --- | --- |
| Mouse | Look around |
| W / A / S / D | Move |
| Double-tap Space | Toggle flying |
| Space | Fly up |
| Shift | Fly down |
| Ctrl | Accelerate |
| Left Click | Break block |
| Right Click | Place block |

## Notes

- Flight-only movement.
- No gravity.
- No collision.
- Green wireframe previews block placement.
